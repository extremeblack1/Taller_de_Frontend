# Consentidos 🐾

## Descripción

**Consentidos** es una propuesta de tienda virtual para mascotas, diseñada para ofrecer una experiencia sencilla, clara y amigable. La página presenta diferentes categorías de productos, una sección de ofertas, productos destacados y un espacio para las redes sociales de la tienda.

El diseño utiliza una combinación de colores pastel, bordes redondeados e imágenes relacionadas con mascotas para mantener una identidad visual cálida y cercana.

## Estructura del proyecto

- `index.html`: estructura y contenido de la página.
- `styles.css`: estilos visuales y distribución de los elementos.
- `img/`: imágenes utilizadas en el sitio.
- `diseno-excalidraw.png`: diseño inicial realizado en Excalidraw.

## Tecnologías utilizadas

- HTML5
- CSS3
- Font Awesome para algunos iconos

No se utilizó JavaScript ni frameworks como Bootstrap o Tailwind.

## Uso de Flexbox

Se utilizó **Flexbox** principalmente para organizar elementos en una sola dirección.

Por ejemplo, se utilizó para:

- Organizar los elementos del encabezado.
- Distribuir las categorías de la barra lateral.
- Alinear el logo, buscador y acciones del usuario.
- Organizar los elementos del pie de página.
- Alinear algunos elementos dentro de las tarjetas.

Flexbox permitió controlar fácilmente la alineación, separación y distribución de los elementos dentro de cada sección.

## Uso de Grid

Se utilizó **CSS Grid** para las partes que necesitan organizar elementos en filas y columnas.

Principalmente se utilizó para:

- Dividir la página entre la barra lateral y el contenido principal.
- Organizar las tarjetas de productos en una cuadrícula de 3 columnas y 2 filas.
- Distribuir algunas partes del pie de página.
- Organizar los elementos internos de las categorías y las tarjetas.

Grid fue elegido para la sección de productos porque permite mantener una estructura clara de filas y columnas y facilita que los seis productos queden distribuidos de manera ordenada.

## Box Model

Se utilizó `box-sizing: border-box` para facilitar el manejo de tamaños, bordes y espacios de los elementos.

También se aplicaron propiedades como:

- `margin`
- `padding`
- `border`
- `width`
- `height`
- `border-radius`

Esto permitió construir los diferentes paneles, tarjetas y secciones manteniendo una distribución consistente.

## Diseño

El desarrollo de la página se realizó tomando como referencia el diseño creado previamente en Excalidraw. Se buscó mantener la distribución general de la propuesta, incluyendo la barra lateral, encabezado, sección de ofertas, productos destacados y pie de página.
